Design notes
  • PENDINGEvent trigger: The trigger that initiates a new event has not been defined yet — to be discussed with the Executive Team. Possibilities include: an annual calendar of recurring events, an ad hoc decision by the Executive Team, a guest request, or an inbound commercial inquiry. This decision also determines how far in advance each department workflow must start.
  • Notion template (Krizia): Krizia created and maintains the event template in Notion. The template has two layers of variables: (1) manually filled — event name, date, type, price, food type, spaces needed, expected attendance; (2) automatically calculated once the manual fields are complete — estimated revenue, estimated cost, estimated gross margin, capacity availability check, and preliminary materials list. Heather reviews the full output before approving.
  • Heather's approval as the gate: Approval is the single trigger that activates all five department workflows in parallel. This prevents departments from starting work before the event is confirmed, avoiding wasted effort. No department should begin preparation without an approved Notion page.
  • Parallel execution: All five department workflows run simultaneously after approval. Each has its own timeline and deliverable. The pre-event checkpoint is the convergence point — all departments must be ready before the event gets a go/no-go.
  • PENDINGFarm participation flag: The Farm lane only activates when the event requires farm produce or a farm activity (harvest experience, farm tour with tasting, etc.). A "Farm involvement: yes / no" flag in the Notion template would make this trigger automatic rather than manual.
  • PENDINGPre-event checkpoint — N days TBD: The review date should be defined per event type. A small day experience may only need 48h, while a residency or multi-day workshop may need 7–10 days. This should be a formula in the Notion template: event date minus N days = checkpoint date.
  • Post-event loop: The results analysis feeds into future event planning. Over time, historical data on attendance, revenue, and feedback scores will allow the system to surface benchmarks and recommendations when planning similar events.
